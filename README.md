# Copilot Auto Approve for VS Code

Automatically approves Copilot and terminal confirmation dialogs.

## Features

- Automatically clicks "Continue", "Approve", "Run Anyway", "Yes" in dialogs
- Runs silently in the background

## Installation

1. Package with `vsce package`
2. Install the `.vsix` file in VS Code via Extensions panel
